# Aether App Store

Der offizielle Download-Laden & Launcher für alle Aether-Apps.

## ⬇ Download
**[AETHER-Store.exe herunterladen](https://github.com/pralle7747-max/AETHER-Store/releases/latest/download/AETHER-Store.exe)** · alle Versionen unter [Releases](https://github.com/pralle7747-max/AETHER-Store/releases)

Voraussetzung: Windows 10/11 mit Microsoft Edge WebView2 (bei Windows 11 vorinstalliert).
Der Store aktualisiert sich danach automatisch selbst.

## ✨ Features
- Moderne Oberfläche mit Animationen, 7 Themes und eigener Akzentfarbe
- **AETHER-Konto** – dasselbe wie in der AETHER-App: Einstellungen & Favoriten auf allen PCs synchron, Geräteübersicht, Postfach
- Alle Aether-Apps an einem Ort – jeder Download wird per **SHA256** geprüft
- Bibliothek als Launcher: Startzähler, „Zuletzt gespielt“, Favoriten, Desktop- & Startmenü-Verknüpfungen
- App-Updates mit einem Klick („Alle aktualisieren“), sicherer Austausch ohne Datenverlust
- **Auto-Update** des Stores selbst
- Befehls-Palette (`Strg K`), Impressum, Datenschutz, Lizenzen

## 🛡 Hinweis zu Virenscannern
Einige wenige KI-/Heuristik-Scanner melden mit Python gebaute Programme manchmal fälschlich. Die großen Hersteller (Microsoft Defender, Kaspersky, BitDefender, ESET, Avast) stufen den Store als sauber ein. Die SHA256-Prüfsumme jeder Version steht am jeweiligen Release.
